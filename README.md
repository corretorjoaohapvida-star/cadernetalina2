# Caderneta da Lina

Página estática da oferta de Black Friday da Lina Criativa.

## Publicar na Vercel

Importe este repositório na Vercel. Use a pasta raiz, preset Other, sem comando de build e diretório de saída `.`. Não precisa instalar dependências.

## Conteúdo

- `index.html`: página aprovada.
- `style.css` e `future.css`: estilos.
- `app.js`: carrossel, ampliação de imagens, FAQ e parâmetros de campanha nos checkouts.
- `assets/`: somente imagens usadas pela página.
